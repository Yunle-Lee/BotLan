# IslandUI 交付包

- `安装器/IslandUI-Setup.exe`：双击安装并启动，默认安装到当前用户目录，无需预装 .NET 或 Node.js。
- `源码/`：完整功能源码、依赖锁文件、资源、测试和安装器构建脚本。
- `SHA256SUMS.txt`：安装文件完整性校验。
- `审查记录.md`：清理范围、修复和测试情况。

## 安装与数据

支持 Windows 10 1809 及以上的 x64 电脑。电脑缺少 WebView2 时，安装程序会通过微软官方组件补装，此时需要网络。安装器会创建桌面和开始菜单快捷方式。

Bot 和模型配置仍由用户自行填写。本交付没有携带现有聊天、文件、API 密钥、账号授权或浏览器配置。旧密钥和旧聊天不会自动复制到别人的电脑。

用户数据在 `%LOCALAPPDATA%\IslandUI`，卸载通过 Windows“已安装的应用”完成，默认保留数据。可选的 Docker 代码执行/浏览器环境与外部账号连接仍需自行配置，不会自动安装或授权。

本安装器尚未用发布者代码签名证书签名，Windows 可能显示未知发布者提示；校验和不是数字签名。

## 本轮重要修复

折叠胶囊保持在动画结束的位置，移出鼠标后在当前胶囊的位置收形为 Long Island，不再跳回旧桌面坐标；拖动胶囊后同样如此。原滑轨退场保留。

源码审查发现并清除了 Code 面板硬编码的模型密钥默认值。对应旧密钥建议在服务商后台撤销或轮换；这里不显示其内容。现有 Bot 配置没有被清空。

参考工程、历史视频、旧备份、独立 Electron 入口、编译缓存及个人数据均未进入源码交付。实际使用的开源版权和许可证集中保留在 `源码/licenses` 和 `源码/THIRD_PARTY_NOTICES.md`，不能当作无关资料删除。
