# 交付审查记录

本轮检查范围是源码整理、隐私信息排除、依赖闭包、构建与安装可用性，不宣称做过完整的渗透测试或穷尽所有安全漏洞。

## 修复与保留

- Chat 收拢时先缩小窗口再移动，避免旧大窗口越界造成系统位置调整。
- Long Island 按当前胶囊中心线和顶部定位，不再使用隐藏窗口的旧坐标；允许 Windows 的一物理像素以内边缘取整。
- 原位返回覆盖胶囊拖动后的场景；右上角滑轨退场计算不变。
- 引擎类统一为 `BotAnimationEngine`。
- Code 面板的硬编码 API 密钥默认值已清空；未修改用户保存的 Bot 配置或聊天数据。
- 安装版优先使用自带 Node，从发布目录定位 Chat；数据与安装目录分离。

## 交付范围

保留 IslandUI、嵌入 Chat、Bot 动画、可选计算与浏览器环境源码、源码资源、锁文件、测试、构建脚本、必需许可证。没有包含 `.env`、真实聊天数据库、浏览器用户资料、`node_modules`、`bin/obj`、旧录屏、参考仓库或旧备份。

当前工作目录中的历史资料没有破坏性删除；本文件夹是新建的干净交付目录。其他桌面目录中的程序未被修改。

## 验证

- Debug/Release 构建以及交付源码独立构建通过。
- 折叠与原位定位专项 23 项检查通过。
- 原页面 30 项检查与前端 18 项单元测试通过，包括密钥默认值和自动写入存储的防回归检查。
- Bot 动画引擎回归通过。旧测试中的完整旋转比较改为浮点容差，未改变动画算法。
- 打包后台使用随包 Node、数据库 WASM、静态页面与隔离 Bot 会话验证，不调用真实模型。
- 安装器在工作区隔离目录进行便携模式部署，禁用快捷方式、系统卸载注册和自动启动；安装后的文件逐个与载荷 SHA-256 比较。
- 最终源码及前端构建产物检查排除常见凭据模式，并新增“API 密钥默认值必须为空”的回归测试。
- 最终源码目录共 1449 个文件、约 40.8 MiB（包括字体和依赖许可），禁带文件及已检查的凭据模式命中均为 0。扫描结果不等同于对未知或任意格式秘密的绝对保证。

## 保留的限制

安装器未做发布者数字签名；缺少 WebView2 的电脑首次补装需要网络。没有在缺少 WebView2 的全新离线电脑或多显示器混合 DPI 环境上验证。可选 Docker 环境和第三方账号连接未进行外部集成测试。

编译仍有原有 `SmallIslandWindow.Icon` 隐藏基类属性的警告。依赖锁文件保留已有依赖版本，未为消除兼容性/弃用警告而批量升级，避免变更现有功能。
